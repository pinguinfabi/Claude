# Neu in Deepforge 0.10.1 – Krit ohne Obergrenze

Beim Serverstart steht im Log `Deepforge 0.10.1 ready`. Ressourcenpaket unverändert (wie 0.10.0).

## Krit-Chance: keine Deckelung mehr
- **Die 60-%-Obergrenze ist weg.** Die Krit-Chance aller angelegten Teile, der Grundwert von 5 %, Glücksrunen, der Frostling und das Talent werden einfach addiert.
- Ab **100 %** trifft jeder Schlag kritisch. Nur was darüber hinausgeht, wird zu Krit-Schaden (höchstens +100 %).
- **Die Krit-Werte pro Gegenstand sind wieder wie vorher.** Die Erhöhung für die tiefen Gebiete aus 0.10.0 ist zurückgenommen:

  | Rarität | Krit pro Teil |
  |---|---|
  | Ungewöhnlich | 1–6 % |
  | Selten | 2–8 % |
  | Episch | 3–10 % |
  | Legendär | 4–12 % |
  | Mythisch | 5–15 % |

  Dazu kommt die Qualität als Faktor.
- Unverändert: Glücksrunen geben zusammen höchstens +10 %.
- Schmiede-Menü, Charakterseite und Wiki sind entsprechend angepasst.
