# Neu in Deepforge 0.7.2

Beim Serverstart steht im Log `Deepforge 0.7.2 ready`. Ressourcenpaket unverändert (wie 0.7.0).

## Ausrüstungs-Sets: „Auf aktiv stellen“ statt Automatik
- Der **automatische Wechsel ist entfernt**. Beim Dungeon-Start und danach wird nichts mehr von selbst umgezogen.
- Unter jedem Set gibt es jetzt den Knopf **„Auf aktiv stellen“** (Smaragd). Damit legst du das Set an.
- Das gerade getragene Set zeigt **„✔ Aktiv“** (grüner Farbstoff), ein leeres Set **„Noch leer“**.
- Speichern, Umbenennen und `/df sets <1-4|Name>` funktionieren wie bisher.
- Alte Automatik-Einstellungen werden beim Laden einfach ignoriert. Es geht nichts verloren.
