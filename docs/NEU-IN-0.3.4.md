# Neu in Deepforge 0.3.4

Beim Serverstart steht im Log `Deepforge 0.3.4 ready`. Ressourcenpaket unverändert.

## Handbuch teleportiert nicht mehr
Das Bergbau-Handbuch war intern ein **Kompass**. Andere Plugins auf dem Netzwerk (Lobby-/Navigator-Plugins) reagieren
auf Kompass-Klicks und haben Spieler teleportiert. Das Handbuch ist jetzt ein **Buch** – Rechtsklick öffnet wie gewohnt
das Deepforge-Menü. Vorhandene Kompasse werden beim Betreten automatisch ersetzt.
Auch die Menü-Knöpfe verwenden keine Kompasse mehr.
