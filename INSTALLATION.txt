DEEPFORGE – OPEN BETA · SERVERPAKET FÜR PAPER 1.21.8
=====================================================

Deepforge ist ein Server-Plugin (keine Fabric-/Forge-Mod) für das Netzwerk Axxin.de.
Benötigt: Minecraft Java 1.21.8, Paper 1.21.8 und Java 21.
Getestete Umgebung: Paper 1.21.8, Citizens 2.0.39 (Build 3887), LuckPerms 5.5.85.
Paper/Minecraft selbst sind nicht in diesem ZIP enthalten.

KURZFASSUNG
-----------
1. Server vollständig stoppen.
2. Lief schon eine ältere Deepforge-Version: nur plugins/Deepforge.jar ersetzen,
   Spielstände bleiben erhalten. Für einen kompletten Neustart: Abschnitt RESET.
3. Den Ordner plugins/ aus diesem ZIP in den Hauptordner des Servers kopieren
   (dort, wo server.properties liegt). Je Plugin nur EINE JAR.
4. Ressourcenpaket einrichten: Variante A, B oder C unten.
5. Server starten (kein /reload). Mit Minecraft 1.21.8 verbinden.
   Deepforge startet automatisch: Dorf, Wald und Minen entstehen beim ersten Start.
   Spieler öffnen das Menü mit Rechtsklick auf das Handbuch oder /df menu.

UPDATE EINER BESTEHENDEN INSTALLATION
-------------------------------------
- Server stoppen, plugins/Deepforge.jar ersetzen, Server starten.
- Die vorhandene plugins/Deepforge/config.yml wird NICHT überschrieben.
  Bei einem neuen Ressourcenpaket die neue SHA-1 aus resourcepack/pack.sha1
  unter resource-pack.sha1 eintragen (oder sha1 leer lassen, siehe Variante C).
- Spielstände, Welt, Gilden und Arbeiter bleiben erhalten. Welt-Umbauten
  (Dorf, Minen, Wald) laufen nach einem Update einmal automatisch.

RESSOURCENPAKET
---------------
Variante A – zum Testen:
  resourcepack/Deepforge-ResourcePack.zip unverändert in den Ressourcenpaket-
  ordner des Minecraft-Clients kopieren, ganz oben aktivieren und im Spiel
  /df pack local eingeben (bestätigt nur, dass das Paket aktiv ist).

Variante B – eigener Webspace:
  Die ZIP unter einer direkten, öffentlichen HTTPS-Download-Adresse ablegen und in
  plugins/Deepforge/config.yml eintragen:
    resource-pack:
      url: 'https://DEINE-DOMAIN/Deepforge-ResourcePack.zip'
      sha1: '<Inhalt von resourcepack/pack.sha1>'
      required: true
  Eine Download-Seite, private Freigabe oder localhost-Adresse funktioniert nicht.

Variante C – Deepforge verteilt das Paket selbst:
  Das Paket steckt auch im Plugin. Mit
    resource-pack:
      sha1: ''
      self-host:
        enabled: true
        port: 8765
  bekommt jeder Spieler beim Betreten automatisch das passende Paket.
  Der Port muss beim Hoster freigegeben sein.

Das Paket enthält das Axxin-Netzwerk-Paket 1:1 (Ränge, Symbole, Logos).
Spieler brauchen also kein zweites Paket.

RÄNGE (LUCKPERMS)
-----------------
LuckPerms 5.5.85 liegt frisch und ohne Benutzerdaten bei. Gibt es schon ein
LuckPerms-Setup: dessen JAR und Daten behalten, die beigelegte nicht installieren.
Ränge werden über Rechte gesteuert, z. B. in der Serverkonsole:
  lp creategroup admin
  lp group admin permission set network.rank.admin true
  lp user SPIELERNAME parent add admin
Weitere Ränge: network.rank.teamleitung, dev, srmod, mod, helper, builder,
media, partner, vip, sub, sub2, sub3 (varo.* wird ebenfalls erkannt).
HOSTER wird in der Deepforge-config.yml unter display.hosters per Name oder UUID
eingetragen. Ohne Rang ist der Name grau.
Details und Farben: docs/TAB-UND-AUTOLOGIN.md.

Deepforge-Rechte:
  deepforge.play   Spielen (Standard: alle)
  deepforge.admin  Admin- und Testbefehle unter /df admin (Standard: OP)

PROXY / NETZWERK (OPTIONAL)
---------------------------
proxy/DeepforgeProxy.jar gehört auf den BungeeCord-/Waterfall-Proxy, nicht auf den
Deepforge-Server. Damit gilt:
  - /deepforge bzw. /df führt von jedem Netzwerk-Server zu Deepforge.
  - Partys aus PartyxFreundeSystem werden automatisch zur Deepforge-Party.
    Sie bleiben auch nach einem Dungeon bestehen.
Einrichtung: docs/PROXY.md.

FRISCHER NEUSTART / RESET
-------------------------
Das ZIP enthält KEINE Spielerprofile, Datenbanken, Welten, Admin-Listen oder
Zugangsdaten. Auf einem neuen Server startet jeder mit 250 $.
Entpacken allein löscht aber keine alten Spielstände. Für einen kompletten Neustart:
  1. Alle Spieler ausloggen lassen und den Server stoppen.
  2. Sichern, dann diese Dateien und Ordner AUS dem Server verschieben:
       plugins/Deepforge/  (inklusive profiles.db, -wal und -shm)
       die Spielwelt deepforge/ (oder der unter world-name eingestellte Name)
  3. Dieses ZIP einsetzen und den Server starten.
Datenbank und Welt entstehen neu. Den Citizens-Ordner nicht pauschal löschen,
dort können fremde NPCs liegen. Andere Welten und Plugins bleiben unberührt.

SERVER-EINSTELLUNGEN
--------------------
IP, Port, Whitelist, Online-Modus und OP-Rechte stellst du wie gewohnt bei deinem
Hoster ein; dieses ZIP enthält keine server.properties. Citizens braucht beim
ersten Start Internetzugang für seine Bibliotheken. Für die Figuren ist weder ein
Client-Mod noch ModelEngine nötig.
