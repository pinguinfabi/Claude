DEEPFORGE – FRISCHES SERVERPAKET FÜR PAPER 1.21.8
====================================================

Das ist ein Server-Plugin, keine Fabric-/Forge-Mod.
Benötigt: Minecraft Java 1.21.8, Paper 1.21.8 und Java 21.
Getestete Umgebung: Paper Build 60, Citizens 2.0.39 Build 3887.
Paper/Minecraft selbst sind nicht in diesem ZIP enthalten.

1. Server vollständig stoppen.
2. Falls dort schon Deepforge installiert war: Abschnitt RESET unten ausführen.
3. Dieses ZIP DIREKT in den Hauptordner des Servers entpacken.
   Dort liegt auch dessen server.properties. Die JARs gehören nach plugins/,
   nicht nach mods/. Es darf jeweils nur eine JAR je Plugin geben.
   Vorhandene ältere JAR-Versionen gegebenenfalls aus plugins/ herausnehmen.
4. Ressourcenpaket einrichten: Variante A oder B unten.
5. Server normal starten. Kein /reload verwenden.
6. Mit Minecraft Java 1.21.8 verbinden. Deepforge startet automatisch!
   Niemand muss /df start eingeben. TAB-Liste und Infotafel sind bereits aktiv.
   Vier freie Inventarplätze für Grundwerkzeuge bereithalten.
   Das Dorf mit Wald und Minen wird beim ersten Eintritt aufgebaut.
   Handbuch: Rechtsklick oder /df menu. Tutorial: /df tutorial.

SHA256SUMS.txt                        Prüfsummen aller enthaltenen Dateien
START-HIER.html                       Übersichtliche Anleitung im Browser

WAS KOMMT WOHIN?
----------------
- Den gesamten plugins/-Ordner dieses ZIPs in den Server-Hauptordner kopieren.
  Ergebnis: SERVER/plugins/Deepforge.jar, Citizens.jar, LuckPerms.jar und
  SERVER/plugins/Deepforge/config.yml. Nicht SERVER/plugins/plugins/ erzeugen.
- Die ZIP aus resourcepack/ gehört entweder in den Ressourcenpaketordner jedes
  Minecraft-Clients oder auf deinen HTTPS-Webspace (siehe unten).
- docs/, source/, licenses/ und die Anleitungsdateien sind Begleitmaterial;
  sie müssen nicht in den plugins/-Ordner.
- Paper 1.21.8 und Java 21 stellt dein Hoster bereit bzw. installierst du separat.

ALLE BISHERIGEN FUNKTIONEN
------------------------
Minen und Dorf, überarbeiteter Wald mit Sägewerk, Arbeiter und Offline-Produktion,
Erz-/Holzglück, Gegenstände und Upgrades, Bosskämpfe und Lebensanzeigen,
Party-Dungeons mit Leveln, Heilung, Tutorials, neue Menüführung sowie die
Varo-TAB/Infotafel mit Rangfarben und automatischem Einstieg sind enthalten.

FRISCHER SPIELSTART / RESET
--------------------------
Das ZIP enthält KEINE Spielerprofile, Datenbanken, gebauten Welten,
Arbeiter-Spielstände, Administratorlisten oder Zugangsdaten.
Auf einem frischen Zielserver startet jeder mit den normalen Anfangswerten.
Level, Geldfortschritt, Ausrüstung, Arbeiter, Boss-/Dungeonfortschritt,
Tutorialfortschritt und Inventare aus unserem Testserver werden nicht übertragen.
Das Anfangsgeld ist 250 $, wie im Spiel vorgesehen.

WICHTIG: Entpacken allein entfernt KEINE bereits vorhandenen Spielstände.
Für einen vollständigen Deepforge-Neustart auf einem bisher genutzten Server:
- Bei noch laufendem Spiel zuerst /df leave ausführen und im normalen Spawn
  ausloggen; bei mehreren Spielern alle Teilnehmer vorher austreten lassen.
- Server stoppen und die Daten sichern.
- Den bisherigen Ordner plugins/Deepforge AUS plugins/ heraus in die Sicherung
  verschieben. Dabei auch profiles.db-wal und profiles.db-shm mitnehmen, falls da.
- Die bisherige Spielwelt deepforge/ aus dem Server-Hauptordner in die Sicherung
  verschieben. Bei abweichendem world-name den tatsächlich konfigurierten
  Deepforge-Weltordner verwenden.
- Erst danach dieses ZIP entpacken und den Server starten.
Die neue Datenbank und Spielwelt werden automatisch erzeugt. Den Citizens-
Datenordner nicht pauschal entfernen: fremde NPCs können dort gespeichert sein.
Deepforge-Arbeiter werden aus den neuen Spielerprofilen erstellt.
Andere Spielwelten und andere Plugins werden durch diesen Reset nicht gelöscht.

RESSOURCENPAKET – VARIANTE A: DIREKT TESTEN
----------------------------------------
Jeder Spieler kopiert resourcepack/Deepforge-ResourcePack.zip unverändert in
den Ressourcenpaketordner seines Minecraft-Clients und aktiviert es ganz oben.
Im Spiel anschließend /df pack local ausführen. Dieser Befehl bestätigt nur,
dass das Paket manuell aktiviert wurde; er lädt keine Datei herunter.
Die beigelegte Konfiguration ist für diesen Weg sofort verwendbar.

RESSOURCENPAKET – VARIANTE B: AUTOMATISCH FÜR ALLE
----------------------------------------------
1. resourcepack/Deepforge-ResourcePack.zip auf deinem Webspace/Hoster unter
   einer öffentlich erreichbaren direkten HTTPS-Download-Adresse bereitstellen.
   Eine Download-Webseite, private Freigabe oder localhost-Adresse funktioniert
   für andere Spieler nicht. Das Ablegen im Serverordner allein hostet keine Datei.
2. Bei gestopptem Server in plugins/Deepforge/config.yml eintragen:

   resource-pack:
     url: 'https://DEINE-DOMAIN/Deepforge-ResourcePack.zip'
     sha1: '42361f15fe80c62c2b9a7e40daf912b5811b7d3e'
     required: true
     textured-menus: true

   Die Beispiel-Domain durch deine echte direkte Download-Adresse ersetzen.
   Die richtige SHA-1 steht schon in der mitgelieferten config.yml.
3. Server starten; Minecraft bietet das Paket beim Eintritt an.
   Erneut anbieten: /df pack. Spieler müssen es annehmen.
   Bei mehreren vorhandenen Ressourcenpaketen ist ein gemeinsames Pack nötig.

SERVER-EINSTELLUNGEN
-------------------
IP, Port, Whitelist, Online-Modus und Adminrechte konfigurierst du über deinen
Hoster bzw. deinen bestehenden Server. Dieses ZIP überschreibt diese nicht.
Es enthält keine server.properties und keine lokal gebundenen Startskripte.
Beim ersten Start benötigt Citizens Internetzugriff für seine Bibliotheken;
Spielerskins können ebenfalls Onlinezugriff benötigen.
Die Spielfiguren benötigen weder einen Client-Mod noch ModelEngine.

LUCKPERMS / RÄNGE
----------------
LuckPerms 5.5.85 (Bukkit-Version) ist frisch und OHNE Benutzerdaten beigelegt.
Downloadquelle: https://luckperms.net/download
Für eine Neuinstallation die mitgelieferte LuckPerms.jar verwenden.
Bei einem bereits vorhandenen LuckPerms-Setup dessen JAR und Konfiguration
beibehalten und die beigelegte Kopie nicht zusätzlich installieren.

Ohne zugewiesenen Rang erscheinen Spieler grau. Neue LP-Gruppen können in der
Serverkonsole so eingerichtet werden (ohne vorangestellten Schrägstrich):
  lp creategroup admin
  lp group admin permission set network.rank.admin true
  lp creategroup vip
  lp group vip permission set network.rank.vip true
  lp user DEIN_SPIELERNAME parent add admin
Den Platzhalter ersetzen und Ränge bewusst vergeben. Die gezeigten Rangrechte
steuern die Darstellung, nicht automatisch sämtliche Server-Adminrechte.
Es sind keine Spieler vorab als Administrator eingetragen.
Alle Rangnamen und Farben: docs/TAB-UND-AUTOLOGIN.md.

Präfixe/Sortierung entsprechen dem Varo-Code. Vorhandene network.rank.*- oder
varo.*-Rechte werden erkannt. HOSTER wird ausdrücklich in display.hosters der
Deepforge-Konfiguration über Name oder UUID eingetragen, nicht durch Wildcards.
